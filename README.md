# Estudos-Projetos-CSharp

Este repositório foi criado para centralizar e organizar meus códigos de estudo, exercícios e projetos práticos desenvolvidos na linguagem **C#** e na plataforma **.NET**.

## 📂 Estrutura do Repositório

O projeto está dividido nas seguintes pastas de tópicos:

*   **Fundamentos de C#**: Conceitos iniciais da linguagem, sintaxe básica, variáveis e tipos de dados.
*   **OperadorComparacao**: Exercícios práticos utilizando operadores de comparação (`==`, `!=`, `>`, `<`, `>=`, `<=`).
*   **Estruturas de Repetição**: Exemplos de lógica utilizando laços de repetição (`while`, `do-while`, `for`, `foreach`).

## 🛠️ Tecnologias Utilizadas

*   **C#** (100% do projeto)
*   **.NET SDK** (recomendado .NET 8.0 ou superior)
*   **IDE/Editor**: Visual Studio ou Visual Studio Code

## 🚀 Como Executar os Projetos

1. Clone o repositório para sua máquina local:
   ```bash
   git clone https://github.com
   ```
2. Navegue até a pasta do tópico que deseja testar:
   ```bash
   cd "Nome-da-Pasta"
   ```
3. Execute o projeto utilizando o terminal do .NET:
   ```bash
   dotnet run
   ```
